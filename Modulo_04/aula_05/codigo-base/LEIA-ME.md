## Como utilizar

- Código 1: copie codigo-01.html como index.html para uma pasta portfolio; copie também app.js. É a base inicial da terça.
- Código 8: base de recuperação com os componentes da terça, sem os componentes novos da quinta. Se precisar dela, copie codigo-08.html como index.html e inclua app.js. Se já tiver seu projeto da terça, continue nele.
- Os outros arquivos HTML e JavaScript são fragmentos para inserir no local indicado no exercício. Não substitua a página inteira por um fragmento.
- Código 11 possui duas partes: codigo-11.html vai no index.html; codigo-11.js deve ser acrescentado ao app.js do projeto, preservando os eventos anteriores.
- Arquivos .txt são prompts para adaptar antes de usar IA.
- As páginas completas usam Bootstrap e Bootstrap Icons por CDN e precisam de internet. Os fragmentos utilizam essas mesmas dependências.
- Siga o objetivo, os passos, os testes e a entrega indicados em cada exercício.
